# T02：Agent Center 页面

> 状态：工程完成  
> 优先级：P0  
> 依赖：T01  
> 阻塞：T10

## 1. 目标

提供一处清晰管理 Agent 执行配置的桌面界面，让用户能创建、编辑、停用和理解 Agent，而不会误以为这是聊天机器人或在线员工系统。

## 2. 页面结构

### 列表区

每张 Agent 卡显示：

- 首字母稳定色标；
- 名称；
- 用途说明；
- 默认 Recipe；
- 默认预算；
- 最大并发；
- 启用/停用状态；
- 被多少 Task / Automation 引用。

### 编辑面板

字段：

- 名称；
- 用途说明；
- 稳定指令；
- 默认 Recipe；
- 默认预算；
- 最大并发；
- 启用状态。

动作：

- 保存；
- 取消；
- 停用/启用；
- 删除（仅无引用时）；
- “用它发起任务”。

## 3. 信息架构

- 侧边栏工作区组新增“Agent”；
- 页面标题为“Agent”；
- 无 Agent 时展示解释性空状态和“创建 Agent”；
- “用它发起任务”跳转 Home，并预选 Agent；
- 不显示虚假在线状态、头像上传或聊天入口。

## 5. 实施步骤

1. 先写 Electron E2E，在旧 UI 上因没有 Agent 导航而 RED；
2. 增加页面路由和侧边栏入口；
3. 实现列表、空状态、创建/编辑表单；
4. 接入启用、停用和删除保护错误；
5. 接入“用它发起任务”；
6. 处理加载、保存中、错误和空状态；
7. 做 900×600 和长文本对抗；
8. 做 reduced-motion 与键盘焦点检查。

## 6. 交互规则

- 保存期间禁止重复提交；
- 删除需要二次确认；
- 被引用时删除按钮禁用并解释原因；
- 停用不是删除；如有启用中的 Automation 引用，明确提示先暂停或改绑；
- textarea 不渲染 Markdown；
- Agent 名称在窄卡片中最多两行；
- 首字母色由 Agent ID 确定，不依赖名称，改名不换色。

## 7. E2E 验收

必须真实覆盖：

1. 空状态；
2. 创建 Agent；
3. 编辑 Agent；
4. 停用、启用；
5. “用它发起任务”进入 Home 且预选正确；
6. 无引用删除；
7. 有引用时删除被阻止，启用中的 Automation 引用时停用被阻止；
8. 应用重启后 Agent 仍存在；
9. Renderer 无 console/page error。

## 8. 视觉验收

- 延续当前桌面工作台设计 token；
- 900×600 可完整操作；
- 10,000 字指令不撑破布局；
- 错误文本与字段关联；
- 状态不只靠颜色；
- 稳定帧视觉评分目标 ≥ 90。

## 9. 明确不做

- 不展示运行指标；
- 不做 Agent 详情独立路由；
- 不做拖拽排序；
- 不上传头像；
- 不编辑 Provider、MCP 或 Shell 权限。

## 10. 完成判据

用户不阅读文档也能创建一个 Agent，并理解它是一套默认执行配置；原 Home 发起路径仍然可用。

## 11. 实测结果（2026-07-23）

- 已完成 Agent 创建、编辑、停启、删除保护、Home 预选与重启持久化；证据见审计记录 AJ。
- 最终九页面矩阵在 Retina 900×600、reduced-motion、键盘焦点和超长中英文数据下通过，Renderer console/page error 为零。
- 未测边界：按范围未实现独立 Agent 详情路由、头像、拖拽排序及 Agent 级 Provider/工具权限。
