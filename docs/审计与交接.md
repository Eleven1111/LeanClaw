**回归验证命令**（在仓库根目录执行；建议每条冒烟用独立 LEANCLAW_DATA_DIR）：

```bash
npm run typecheck && npm test && npm run build
npm run e2e                                                                       # 3 条 Playwright E2E（需先 build）

# 15 条冒烟（s1–s15）：
npm run smoke                                                                     # s1 预期 delivered
LEANCLAW_FAULT=bad_citation LEANCLAW_SMOKE_EXPECT=verification_failed npm run smoke                       # s2
LEANCLAW_FAULT=tool_fail    LEANCLAW_SMOKE_EXPECT=cancelled_by_user   npm run smoke                       # s3
LEANCLAW_SMOKE_INPUT=/nonexistent/x.md LEANCLAW_SMOKE_EXPECT=cancelled_by_user npm run smoke              # s4
LEANCLAW_FAULT=forbidden_path LEANCLAW_SMOKE_EXPECT=cancelled_by_user npm run smoke                       # s5
LEANCLAW_WEB_MOCK=1 LEANCLAW_SMOKE_RECIPE=deep-research npm run smoke                                     # s6
LEANCLAW_WEB_MOCK=1 LEANCLAW_SMOKE_RECIPE=deep-research LEANCLAW_FAULT=bad_citation LEANCLAW_SMOKE_EXPECT=verification_failed npm run smoke  # s7
LEANCLAW_SMOKE_RECIPE=content-pack npm run smoke                                                          # s8
LEANCLAW_SMOKE_RECIPE=content-pack LEANCLAW_FAULT=banned_word LEANCLAW_SMOKE_EXPECT=verification_failed npm run smoke  # s9
LEANCLAW_SMOKE_MULTI=5 LEANCLAW_MAX_ACTIVE=3 npm run smoke                                                # s10 并发排队
LEANCLAW_FAULT=expensive_model LEANCLAW_SMOKE_BUDGET=0.05 LEANCLAW_SMOKE_EXPECT=cancelled_by_user npm run smoke  # s11 预算击穿
LEANCLAW_SMOKE_REFINE=1 npm run smoke                                                                     # s12 增量 Run
LEANCLAW_FAULT=primary_500 LEANCLAW_TIERMAP='{"generation":{"providerId":"p1","model":"fake-model","fallback":{"providerId":"mock","model":"mock-local"}}}' LEANCLAW_SMOKE_PROVIDERS='[{"id":"p1","name":"FakePrimary","kind":"openai-compat","baseUrl":"http://127.0.0.1:1","defaultModel":"fake-model","apiKey":"x"}]' npm run smoke  # s13 模型故障转移
LEANCLAW_SMOKE_MCP=1 npm run smoke                                                                        # s14 MCP 链路
LEANCLAW_SHELL=1 LEANCLAW_SHELL_ALLOW='echo ' LEANCLAW_SMOKE_SHELL=1 npm run smoke                        # s15 Shell 三级风险与执行
```

**架构不变量**（违反即审计不通过）：状态转换只经 `state.ts::transition()`；delivered 唯一入边是 verifying；工具调用必经 Registry + 三级风险；不可逆写入必过 Diff+Approval；事件只追加不修改；关键失败必须停线；步骤可重入、写入幂等；Renderer 保持 sandbox。

### 记录 G：UI 动效升级（Emil Kowalski 设计工程方法论，2026-07-10）

**执行**：Fable 5 直接执行（skill 加载于主会话上下文，转述给 subagent 会失真）。纯 CSS 改动（styles.css），零组件逻辑变更、零新依赖。
